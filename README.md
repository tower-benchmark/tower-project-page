# TOWER project page

Research project website: https://tower-benchmark.com

Static HTML, CSS and JavaScript with local figure and video assets. GitHub Pages publishes the root of the `main` branch.

Edit `index.html`, `style.css`, `app.js`, or `data.js` and push to `main` to publish. Preserve `CNAME` for the custom domain.

The project trailer is `assets/tower-trailer-v2.mp4`. The original research code is at https://github.com/tower-benchmark/TOWER.

The paper PDF is not hosted while it is being finalized.

Raw simulation dataset (600 episodes): https://huggingface.co/datasets/tower-benchmark/TOWER-SimData

Simulator assets: https://huggingface.co/datasets/tower-benchmark/TOWER-Assets
